# Bushra Basharat — Portfolio

> **AI Automation Engineer & GoHighLevel (GHL) Specialist**
> This portfolio showcases Bushra's GoHighLevel work (funnels, CRM pipelines, workflow automations,
> snapshots, AI Employee & Voice AI), plus AI agents, n8n automation and full-stack projects.

This is a modern, responsive portfolio built with React (JSX) and Tailwind CSS. It is a static front-end only project tailored for Bushra Basharat.

Getting started

Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```

Build:

```bash
npm run build
```

Notes

- No backend included. The contact form is UI-only.
- Tailwind is configured in `tailwind.config.cjs`.


## Regenerating the CV

The downloadable resume is generated from ``scripts/build_resume.py``:

```bash
pip install reportlab
python scripts/build_resume.py   # writes public/Bushra_Basharat_CV.pdf
```
